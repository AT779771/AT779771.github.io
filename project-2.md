# Project 2: Research, Notes & Learning Journal

## Overview
This project is a structured space for documenting my learning, ideas, experiments, and reflections. It acts as a personal knowledge base and helps turn everyday work into a record of growth.

## Purpose
The notebook format allows me to:

- track progress on projects and assignments
- document what I learn over time
- reflect on mistakes, discoveries, and improvements
- keep a clear history of technical and creative development

## What This Project Includes

- notes on concepts and ideas
- code or technical examples
- reflections on challenges and lessons learned
- summaries of progress and next steps

## Why It Matters

Documentation is one of the most valuable habits in any field. By recording what I learn, I can revisit ideas later, build on previous work, and see how my thinking evolves over time.

## Key Takeaways

- reflection improves understanding
- organized notes make learning easier to revisit
- a project is stronger when the process is visible
